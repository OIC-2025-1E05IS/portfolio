# ポートフォリオ（ホワイト×ベージュ）

## 開き方
`index.html` をブラウザで開いてください。CSSは `style.css` として同じフォルダに置いてあります。

## 画像を差し替える
次の画像を `image` フォルダに入れると、プレースホルダーの代わりに表示されます。
- `pro_icon.png`：プロフィール画像
- `work1.png`：病院Webサイトの作品画像
- `work2.png`：企業サイトの作品画像

制作実績カードをクリックすると詳細ポップアップが開きます。病院Webサイトの詳細内にGitHubリンクを設置済みです。
企業サイトの公開URLが決まったら、`index.html` の `projectDetails.site.links` にリンクを追加してください。
